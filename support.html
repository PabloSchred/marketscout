Support

Having a problem?

First refresh Facebook Marketplace and confirm MarketScout is enabled in chrome://extensions. Facebook changes its interface regularly, so include your Chrome version and a screenshot when reporting a display or filtering issue.

Common fixes

  • Refresh the Marketplace page after updating MarketScout.
  • Use Reset filters if a saved filter is hiding results.
  • Keep Turbo mode enabled for faster browsing.
  • Single Include keywords can use Smart Facebook Search; comma-separated lists are local OR filters.
