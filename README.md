# MarketScout Website — GitHub Pages

This folder is ready to upload as the root of a GitHub repository.

After uploading:
1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**.
5. Click **Save**.
6. Wait for GitHub to publish the site.

Your privacy policy will be available at:
`https://YOUR-GITHUB-USERNAME.github.io/YOUR-REPOSITORY-NAME/privacy.html`

Use that exact public HTTPS URL in the Chrome Web Store privacy-policy field.
